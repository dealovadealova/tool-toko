Generator Toko Online
Satu file HTML per klien. Produk, pengaturan, dan pesanan diatur dari Google Sheet.

1. Hubungkan Sheet dan Backend

  1. Import template-toko-sheet.xlsx ke Google Sheets, lalu isi data klien.
  2. Share sheet: Anyone with the link: Viewer.
  3. Extensions > Apps Script, tempel Code.gs, lalu Deploy > New deployment > Web app (Execute as Me, Anyone). Salin URL /exec.

2. Tema (20 pilihan)

Tema diatur dari halaman ini. Untuk mengganti tema, pilih tema lalu download dan upload ulang HTML toko.

3. Fitur saat generate

Fitur yang dimatikan di sini tidak muncul di toko, walaupun Sheet mengaktifkannya. Fitur yang aktif tetap bisa dimatikan dari Sheet.

4. Unduh

Upload file ini ke Cloudflare Pages (Direct Upload). Setelah itu cukup edit Google Sheet. Isi url_toko di Settings dengan alamat hasil upload agar tautan share berfungsi.
